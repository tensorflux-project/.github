# TensorFlux community

**Readable programs. Explicit data. Verifiable compilation.**

We are building TensorFlux: an experimental open-source language, compiler and
runtime for precise byte processing and mathematical, multidimensional computation.
The project was initiated by Christian Herbstritt and is open to contributors who
value clear semantics, reproducible evidence and thoughtful independent review.

- [TensorFlux source and quickstart](https://github.com/tensorflux-project/tensorflux).
- [Current implementation scope](https://github.com/tensorflux-project/tensorflux/blob/HEAD/docs/STATUS.md).

- [Find a first contribution](https://github.com/tensorflux-project/tensorflux/blob/HEAD/docs/community/START_HERE.md).
- [Contribution and review criteria](https://github.com/tensorflux-project/tensorflux/blob/HEAD/CONTRIBUTING.md).

TensorFlux is in Phase 0. Its Python reference implementation and bounded native
compiler paths have local evidence; the initial source upload is being prepared; full-language selfhosting, full LLVM support and
broad platform parity remain open goals. Specifications, counterexamples,
documentation and verification are all useful contributions.

## A public-interest mission

The intended community has a nonprofit-oriented mission: sustain public source,
accessible learning and verifiable compiler engineering. GitHub Sponsors enrollment
is pending; no payment channel or charitable/tax-deductible status is asserted.
Read the [support principles](https://github.com/tensorflux-project/tensorflux/blob/HEAD/docs/community/DONATIONS.md)
before any future monetary contribution. Support does not buy a merge or bypass review.

Project-owned code and documentation are MIT licensed. Everyone follows the
[Code of Conduct](https://github.com/tensorflux-project/tensorflux/blob/HEAD/CODE_OF_CONDUCT.md);
security reports follow the [Security Policy](https://github.com/tensorflux-project/tensorflux/blob/HEAD/SECURITY.md).
